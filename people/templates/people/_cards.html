{% load people_tags %}{% comment %} Renders a spec-driven form as the stack of numbered cards the design shows. Walks `form.layout` (built by people.formbuild.add_card_fields), so the page shape comes from spec.py and this template never needs editing when a card gains a field. Row tables render from the card's `columns`, with one blank row always present so the table is usable without pressing Add first. Layout comes from the spec too: `col_class` is how many of the card's twelve columns a field takes, `newline` starts a fresh line so a group of related questions is never split across two, and `heading` prints a sub-heading above the field it is on. None of it is decided here — a template that made layout decisions would have to be edited every time a card changed, which is the whole thing this file exists to avoid. Expects: form, carrying .layout and .rows_initial Note on comments: no template in this module uses the hash form of a comment. Django's lexer has no DOTALL flag, so a hash comment that spans two lines is not recognised as a comment at all — it renders as visible text and swallows the rest of the page.
