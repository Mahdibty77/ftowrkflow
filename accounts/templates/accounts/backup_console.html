Automatic backups

Backups run automatically around 00:00 (Asia/Tehran), stored in three folders under the host backups directory (next to the project):

  • Every night — database (cases, people, seats, histories…) → backups/db/ftdb_*.tar.gz. The newest 33 days are kept; older daily files are deleted.
  • Every 3 days — media (avatars, stamps, signatures) → backups/media/ftmedia_*.tar.gz. Kept for 10 days; older media archives are deleted.
  • Every 3 days — large code SQLite tables → one file backups/code_db/ftcode_db.tar.gz that replaces the previous snapshot.

Copy the whole backups folder to another drive for off-site safety. The license is intentionally not included in backups.

Run backup now takes an immediate snapshot of the database and media on this server (code tables stay on the 3-day schedule). The page refreshes while it runs.
